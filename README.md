# Hotel Grand Benale — Luxury Boutique Hotel Website

A modern, elegant, and responsive website built for **Hotel Grand Benale**, a premier 4-star boutique hotel in **Kannur, Kerala, India**.

## 🌟 Highlights & Features

- **Brand Design System**:
  - Warm obsidian dark theme (`#0d1214`) with royal gold accents (`#dca11d`), frosted glassmorphism (`backdrop-blur`), and refined serif typography (`Playfair Display`, `Cormorant Garamond`, `Inter`).
  - Sourced photography and official branding from the Hotel Grand Benale repository.

- **Interactive Booking Widget & Direct Reservation Bar**:
  - Live floating reservation widget on the Hero section (Check-in, Check-out, Room Type, Guests).
  - Modal with **instant WhatsApp booking generator** and **pre-formatted Email booking enquiry**.

- **Key Sections**:
  1. **Navbar**: Sticky frosted glass navbar with responsive mobile drawer, quick phone dialer, and direct booking CTA.
  2. **Hero**: High-impact twilight facade with verified guest rating badge (8.8/10 on Expedia) and interactive reservation bar.
  3. **About & Heritage**: Editorial 2-column layout celebrating warm Malabar hospitality, boutique comfort, and key property statistics.
  4. **Rooms & Suites**: Interactive room showcase (`Standard Double Room`, `Deluxe Double Room`, `Grand Benale Luxury Suite`) with category filters, pricing, amenity tags, and dedicated **Room Details Modal**.
  5. **Dining**: Showcase for the in-house multi-cuisine restaurant, coastal Malabar seafood delicacies, breakfast buffet, and 24/7 room service.
  6. **Banquets & Events**: Dedicated MICE and celebration hall showcase for conferences, engagements, and social banquets.
  7. **Amenities**: Minimalist icon grid detailing Wi-Fi, ample parking, elevators, climate control, 100% generator power backup, and round-the-clock front desk.
  8. **Photo Gallery**: Categorized photo collection with a full-screen **Lightbox Viewer** featuring arrow navigation and keyboard shortcuts (`Esc`, `ArrowLeft`, `ArrowRight`).
  9. **Testimonials**: Verified guest reviews with star ratings and authentic traveler tags (Family, Corporate, Solo, International).
  10. **Location & Attractions**: Interactive Google Map of Kakkad Road, Kannur, paired with distances & drive times to Payyambalam Beach, St. Angelo Fort, Railway Station, and Kannur International Airport.
  11. **Footer**: Contact details, social links, direct booking perks, and functioning newsletter subscription.
  12. **Mobile Floating Action Bar**: Sticky mobile bottom bar with quick click-to-call, WhatsApp chat, and instant reservation button.

## 🚀 Tech Stack

- **React 19**
- **Vite 8**
- **TypeScript**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Lucide React Icons**

## 💻 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
